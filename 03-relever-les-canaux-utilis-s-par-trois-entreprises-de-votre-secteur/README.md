# Relever les canaux utilisés par trois entreprises de votre secteur

Rappel théorique et contexte Avant de vous lancer dans cette analyse concrète, il est crucial de consolider les définitions clés. Un canal de marketing digital est une interface numérique par laquelle une entreprise communique avec son marché pour atteindre des objectifs commerciaux. Ces canaux se catégorisent selon deux axes principaux : le coût (gratuit vs payant) et le contrôle (propriété de l'espace). On distingue ainsi les canaux propriétaires (ou owned), comme un site web ou une newsletter, que l'entreprise contrôle entièrement. Les canaux gagnés (ou earned), tels que les articles de presse ou les avis clients, sont des mentions obtenues gratuitement par l'action d'autrui. Enfin, les canaux payants (ou paid), comme la publicité sur les réseaux sociaux ou le référencement payant (SEA), nécessitent un investissement financier pour obtenir de la visibilité. Un modèle mental efficace consiste à voir ces canaux comme un écosystème où chaque élément a un rôle et un coût spécifique, contribuant à une stratégie globale. Une erreur fréquente des débutants est de confondre la présence sur un canal avec une stratégie sur ce canal. Par exemple, une entreprise peut avoir une page Facebook sans jamais y publier de contenu cohérent, ce qui n'en fait pas un canal stratégiquement utilisé. Un autre écueil est de négliger les canaux propriétaires, pourtant essentiels pour la rétention et la fidélisation à long terme, au profit d'une focalisation exclusive sur l'acquisition payante.
