# Présenter en une page l'activité que vous suivrez tout le cursus

Rappel théorique fondamental Dans la continuité de vos premiers pas, cet atelier vous invite à vous placer immédiatement dans la peau d'un stratège en marketing digital. Le point de départ de toute stratégie efficace est la compréhension profonde de l'entité pour laquelle vous allez agir. Ce n'est ni une description superficielle, ni un simple copier-coller des pages de présentation. Il s'agit de construire une vision systémique, en identifiant les éléments clés interdépendants qui définissent une entreprise ou une activité. Le modèle mental à adopter est celui d'une photographie initiale, aussi précise que possible, sur laquelle vous vous appuierez pour toutes les décisions futures. Une erreur fréquente est de sauter cette étape, ou de la traiter avec légèreté, en se lançant directement sur des actions tactiques sans cadre clair. Une autre erreur est la redondance : se contenter de décrire le produit sans comprendre son écosystème opérationnel et concurrentiel. Prenez l'exemple d'une jeune marque de chaussures éco-responsables. Une description basique dirait : "nous vendons des baskets en coton bio". Une analyse systémique, elle, identifierait : le cœur d'activité (la conception et la vente directe en ligne), les opérations clés (partenariats avec des ateliers certifiés, logistique neutre en carbone), le marché (la mode durable, en croissance mais fragmentée), le cœur de cible (les urbains de 25-40 ans, sensibles à l'environnement, prêts à payer un prix premium) et la proposition de valeur unique (transparence totale sur la chaîne d'approvisionnement et design contemporain).
