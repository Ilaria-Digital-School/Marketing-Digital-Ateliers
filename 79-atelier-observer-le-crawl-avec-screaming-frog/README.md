# Atelier : observer le crawl avec Screaming Frog

Rappel théorique Un moteur de recherche découvre les pages web grâce à des robots (crawlers) qui suivent les liens de page en page. Cette phase, appelée « crawl » ou exploration, précède l'indexation : sans exploration réussie, une page ne peut pas être positionnée dans les résultats. Le mental model à retenir est simple : imaginez une araignée qui part d'une page d'accueil, suit chaque lien qu'elle rencontre, note ce qu'elle trouve (URL, code de réponse HTTP, titre, méta-description, balises), puis continue. Screaming Frog SEO Spider est un logiciel de bureau qui reproduit ce comportement à votre demande : il crawle un site comme le ferait Googlebot et vous restitue un tableau exhaustif des pages et de leurs caractéristiques techniques. Les erreurs fréquentes des débutants sont : confondre crawl et indexation, ignorer les codes de statut HTTP (une page en 404 est cassée, une redirection 301 est permanente, une 302 temporaire), ou négliger les pages orphelines et les chaînes de redirection. On oublie aussi souvent que les balises title et meta description manquantes ou dupliquées nuisent directement au SEO. Mini-exemple : vous lancez un crawl sur un site de 200 pages. Screaming Frog vous signale 15 pages en 404, 8 titles dupliqués et 30 pages sans meta description. Vous venez d'identifier concrètement les premiers chantiers d'optimisation technique du site.
