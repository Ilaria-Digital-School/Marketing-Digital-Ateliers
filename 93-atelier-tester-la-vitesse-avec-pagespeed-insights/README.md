# Atelier : tester la vitesse avec PageSpeed Insights

RAPPEL THÉORIQUE La vitesse de chargement est aujourd'hui un facteur de classement officiel de Google et un levier majeur d'expérience utilisateur. Elle s'évalue notamment via les Core Web Vitals, trois métriques introduites dans le chapitre précédent : le LCP (Largest Contentful Paint, temps d'affichage du plus gros élément visible, idéalement inférieur à 2,5 s), le INP (Interaction to Next Paint, réactivité aux interactions, à viser sous 200 ms) et le CLS (Cumulative Layout Shift, stabilité visuelle, à maintenir sous 0,1). PageSpeed Insights (PSI) est l'outil gratuit de Google qui mesure ces indicateurs et attribue un score de performance de 0 à 100. Le bon mental model à adopter : PSI distingue les données de laboratoire (simulation en conditions contrôlées, disponibles pour toute URL) des données de terrain (mesures réelles d'utilisateurs, uniquement si le trafic est suffisant). Ne confondez pas le score global avec les métriques individuelles : un score correct peut masquer un CLS problématique. Erreurs fréquentes : se focaliser sur le seul chiffre du score au lieu d'analyser chaque métrique ; ignorer la différence mobile/desktop (Google indexe en mobile-first) ; négliger la section « Opportunités » qui liste des actions concrètes. Mini-exemple : une page affiche un score mobile de 62, avec un LCP de 4,1 s causé par une image hero non compressée.
