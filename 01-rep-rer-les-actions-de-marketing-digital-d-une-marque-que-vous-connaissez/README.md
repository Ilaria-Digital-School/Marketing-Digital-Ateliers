# Repérer les actions de marketing digital d'une marque que vous connaissez

Rappel théorique : Les fondements du marketing digital observables Le marketing digital désigne l'ensemble des actions et stratégies de marketing mises en œuvre sur les canaux numériques pour atteindre les objectifs d'une entreprise. Ces objectifs sont structurés autour de cinq grandes familles d'actions : l'acquisition, l'engagement, la conversion, la fidélisation et la recommandation. Chaque action visible s'inscrit dans une intention stratégique. Un modèle mental utile pour l'analyse est celui de l'entonnoir numérique de conversion, souvent lié au modèle AIDA. Il décrit le parcours d'un prospect, depuis la prise de conscience d'un besoin jusqu'à l'achat et l'engagement post-achat. Votre rôle est de classer ce que vous observez dans les étapes de cet entonnoir : Attirer l'attention, Susciter l'intérêt, Créer le désir, et déclencher l'Action. Une erreur fréquente consiste à considérer toute publication sur les réseaux sociaux comme une action de marketing pur. Il faut distinguer la communication corporate ou institutionnelle, qui informe ou valorise l'image, de la communication commerciale, qui vise un résultat commercial précis. Par exemple, un post Instagram annonçant un nouveau produit et incluant un lien 'Acheter maintenant' est une action marketing. Un post sur les valeurs de l'entreprise est une action de communication. Un mini-exemple : une marque de café utilise Facebook Ads pour cibler les amateurs de café dans une ville spécifique. Le message est 'Découvrez notre café bio en promotion à -20% cette semaine seulement'. Cette action est clairement une action marketing digitale d'acquisition.
