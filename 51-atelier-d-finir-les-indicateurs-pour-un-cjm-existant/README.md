# Atelier : définir les indicateurs pour un CJM existant

**Rappel théorique** Les KPIs (Key Performance Indicators) associés à un Customer Journey Map (CJM) permettent de transformer une carte de parcours en outil de pilotage opérationnel. Sans indicateurs, le CJM reste un document statique et purement descriptif. Avec des KPIs bien définis, il devient un tableau de bord vivant qui oriente les décisions marketing. Le principe fondamental est d'aligner chaque étape du parcours (Awareness, Consideration, Decision, Retention, Advocacy) avec des métriques qui mesurent à la fois la performance business et l'expérience utilisateur. On distingue deux grandes familles : les métriques quantitatives (taux de conversion, taux d'ouverture, coût par lead, taux de rebond, durée de session, NPS, taux de churn…) et les métriques qualitatives (scores de satisfaction, verbatims, résultats de sondages post-interaction). L'erreur la plus fréquente chez les débutants est de multiplier les indicateurs sans hiérarchie, ce qui noie l'analyse dans la donnée. Une autre erreur classique consiste à utiliser les mêmes KPIs pour toutes les étapes du parcours, sans tenir compte de l'intention de l'utilisateur à chaque phase. Exemple concret : pour un site e-commerce, à l'étape Awareness, on mesurera le coût par clic et le taux d'impression ; à l'étape Decision, on suivra le taux d'abandon de panier et le taux de conversion ; à l'étape Retention, on pilotera le taux de réachat et le score NPS.
