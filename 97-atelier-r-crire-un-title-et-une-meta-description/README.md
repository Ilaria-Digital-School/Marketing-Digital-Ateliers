# Atelier : réécrire un Title et une Meta Description

RAPPEL THÉORIQUE Le Title (balise ) et la Meta Description sont deux éléments de code affichés dans les résultats de recherche (SERP). Le Title est le titre cliquable bleu, la Meta Description est le court texte descriptif situé en dessous. Le Title est un facteur de classement direct pour Google : il doit contenir le mot-clé principal, idéalement en début de balise, et rester lisible pour un humain. La Meta Description n'est pas un facteur de classement, mais elle influence fortement le taux de clic (CTR) : c'est votre argumentaire commercial. Mental model utile : imaginez la SERP comme un rayon de supermarché où chaque résultat est un produit. Votre Title est l'étiquette du produit, votre Meta Description est l'accroche marketing sur l'emballage. L'internaute scanne, compare, et clique sur ce qui répond le mieux à son intention. Erreurs fréquentes : dépasser les longueurs recommandées (~50-60 caractères pour le Title, ~150-160 pour la Meta), bourrer de mots-clés (keyword stuffing), rédiger des Titles génériques (« Accueil », « Nos services »), oublier l'intention de recherche, négliger le call-to-action dans la Meta. Mini-exemple. Mauvais : Title « Chaussures - Boutique en ligne | Site officiel » / Meta « Bienvenue sur notre site de chaussures. » Bon : Title « Chaussures de running homme pas chères | Livraison 24h » / Meta « Découvrez notre sélection de chaussures de running pour homme dès 39 €.
