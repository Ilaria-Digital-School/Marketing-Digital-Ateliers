# Atelier : identifier les éléments clés d’une SERP

RAPPEL THÉORIQUE Une SERP (Search Engine Results Page) est la page de résultats affichée par un moteur de recherche après qu'un internaute a saisi une requête. Dans les chapitres précédents, vous avez vu comment un moteur explore le web (crawl) puis stocke les pages jugées pertinentes (indexation). La SERP est l'aboutissement de ce processus : c'est là que Google décide quels contenus indexés montrer, dans quel ordre et sous quelle forme. Le bon mental model est de considérer la SERP non comme une simple liste de dix liens bleus, mais comme une page composite. On y trouve des résultats organiques (non payants), des résultats payants (annonces Google Ads, souvent marqués « Sponsorisé »), et de nombreuses fonctionnalités enrichies : featured snippet (position zéro), People Also Ask (autres questions posées), Knowledge Panel, pack local (carte + fiches), carrousel d'images, vidéos, avis étoilés, sitelinks, etc. Un résultat organique classique se compose d'un titre cliquable (balise title), d'une URL et d'une méta-description. Comprendre ces briques est essentiel pour optimiser sa visibilité. Erreurs fréquentes : confondre résultat payant et résultat organique ; croire que la position 1 est toujours un lien bleu (souvent, c'est un featured snippet) ; ignorer que la SERP varie selon la localisation, l'appareil et l'historique de l'utilisateur.
